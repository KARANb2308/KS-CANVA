# Playbook — ขั้นตอนที่ได้ผล (อ่านก่อนเริ่มงาน)

สูตรทำงานแยกตามประเภทงานของโปรเจกต์นี้ กลั่นจาก `docs/worklog.md`
- **ได้ผล (วันที่)** = ใช้จริงแล้วผ่าน · **ยังไม่ได้ลองจริง** = มาจากการอ่านโค้ด ใช้ด้วยความระวัง แล้วอัปเดตหลังลอง
- จบงานแล้ว ถ้าได้วิธีใหม่ เจอกับดัก หรือพบว่าสูตรเดิมผิด → แก้ข้อนั้นในไฟล์นี้ (สั้น ใช้ซ้ำได้ ไม่ใช่เล่าเรื่อง)
- หัวข้อ = ประเภทงานที่เจอบ่อยในโปรเจกต์ (เช่น "แก้หน้าจอ", "เพิ่ม API", "แก้บั๊กการบันทึก") เพิ่มหัวข้อใหม่เมื่อเจองานประเภทใหม่

## 0. ทุกงาน — เริ่มและจบ
1. อ่าน `CLAUDE.md` (ถ้ามี) → ไฟล์นี้ → `grep -n "<คำสำคัญของงาน>" docs/worklog.md` ดูงานที่คล้ายกัน
2. `git status --short` และ `git log --oneline -10` ดูว่ามีงานค้าง หรือมีคนแก้อะไรมาก่อนหรือไม่
3. ทำงาน → ตรวจด้วยหลักฐานจริงจากที่ที่ผู้ใช้ดู
4. ต่อท้าย `docs/worklog.md` + อัปเดตไฟล์นี้ → commit ไปพร้อมงาน
