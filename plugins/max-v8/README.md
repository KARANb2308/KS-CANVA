# MAX v8.4 (KS HOME)

ชุดทำงานสร้างและแก้โค้ดสำหรับ Claude ประเมินขนาดงาน (S/M/L) เขียน SPEC ที่มี coverage id ให้ coder ทำแบบเทสก่อน
มี reviewer และ verifier แยกกัน และไม่ยอมบอกว่า "เสร็จ" จนกว่าจะมีหลักฐานจากที่ที่ผู้ใช้ดู รายงานเป็นภาษาไทย

**มีอะไรใหม่ใน v8.4**
- **แผนที่งาน** `docs/roadmap.md`: กำลังทำ / ถัดไป / รอผู้ใช้ / เสร็จล่าสุด (สั่ง `status` ดู)
- **แฟ้มงาน** `docs/max-jobs/<id>/`: แผน + หลักฐานของทุกงาน M ขึ้นไป commit ไปพร้อมงาน ไม่หายเมื่อเปิด session ใหม่
- **ทำต่อ**: พิมพ์ "ทำต่อ" MAX กู้งานที่ค้างจากแฟ้มแล้วทำต่อ
- **ตรวจซ้ำ / ตรวจซ้ำละเอียด**: พิมพ์ "ตรวจซ้ำ <งาน>" ตรวจงานที่ปิดแล้วใหม่ทุกข้อ (ละเอียด = เพิ่มตัวล่าบั๊กและ code-review)
- **แผนภาษาคน**: SPEC ขึ้นต้นด้วยแผน 5–10 บรรทัด งาน L/XL หยุดรอคำว่า "ลุย"
- **สถิติ**: `stats` วัดงาน แจ้งซ้ำ และข้อที่ยังไม่ได้ตรวจ

- **MAX**: พิมพ์ "MAX" หรือ "ทำแบบ MAX"
- **MAX สุด (v8.3)**: พิมพ์ "MAX สุด" เท่านั้น (ระบบไม่เลือกเอง) ทำแบบ L ทุกด่าน และให้ที่ปรึกษา (Fable) ช่วยทำ SPEC รีวิวส่วนสำคัญ และรีวิวงานทั้งหมดตอนท้าย (≤ 5 ครั้ง)
- **MAX ละเอียด (v8.1)**: พิมพ์ "ตรวจละเอียด" / "MAX ละเอียด" ให้ตรวจและวางแผนครบก่อน แล้วหยุดรอคำว่า "ลุย"
- **ความจำงาน (v8.2)**: ทุกงานจะบันทึกลง `docs/worklog.md` และสรุปขั้นตอนที่ได้ผลไว้ใน `docs/playbook.md` ของโปรเจกต์
