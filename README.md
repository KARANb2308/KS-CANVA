
ค้นหาสินค้าวัสดุ + สร้างงานนำเสนอ Material Selection
เว็บหน้าเดียวสำหรับ

ค้นหาข้อมูลสินค้าจาก 4 แหล่ง เลือกแหล่งได้ทุกครั้งที่ค้นหา
บุญถาวร และ HomePro: ค้นด้วยรหัสสินค้า (ใส่หลายรหัส หรือวางลิงก์หน้าสินค้าได้)
ตราเพชร และ Eco door: ค้นด้วยชื่อสินค้า (เว็บไม่มีรหัสสินค้า) แล้วกด “เพิ่มลงงานนำเสนอ” ที่สินค้าที่ต้องการ
ตราเพชร SPC (dbp.co.th): วางลิงก์หน้าสินค้า เช่น พื้น SPC · การ์ดผลค้นหามีปุ่ม + เลือกบัวสำหรับพื้นนี้ (สีที่เว็บแนะนำเลือกให้อัตโนมัติ เลือกขนาดและจำนวน แล้วรวมเป็นชุดเดียวกับพื้นหรือแยกรายการได้)
บัว PVC ตราเพชร สำหรับพื้นอื่น ๆ: ปุ่ม + เพิ่มบัว (ตราเพชร) ทุกหน้า หรือ + เลือกบัว ที่รายการพื้น (ต้องเปิดผ่าน start.bat หรือระบบออนไลน์)
ได้ชื่อ ยี่ห้อ ราคา/ส่วนลด รูปภาพทั้งหมด ข้อมูลจำเพาะ รายละเอียด และดาวน์โหลดผลเป็น CSV
สร้างไฟล์งานนำเสนอ Material Selection Confirmation (.pptx, A4 แนวนอน) แล้วนำเข้า Canva เพื่อแก้ไขต่อ
โลโก้ KS HOME เป็นค่าเริ่มต้น เปลี่ยนหรือไม่ใช้โลโก้ได้
เพิ่ม/ลบ/เรียงหน้าเอง เปลี่ยนหัวข้อ ใส่ข้อความใต้หัวข้อ ใส่ภาพแปลน/3D และชี้ตำแหน่งสินค้าในภาพ (หมายเลข / ลูกศร / เส้น+หมายเลข)
เลือกสินค้าและจำนวนในแต่ละหน้า และเลือกข้อมูลที่จะแสดง
แก้ไข / เลือกรูป: เลือกรูปสินค้าจากรูปทั้งหมดบนเว็บ หรืออัปโหลดรูปเอง แก้ชื่อ ราคา สี ขนาด ฯลฯ ได้
เพิ่มสินค้าเอง: สำหรับสินค้าที่ไม่มีในเว็บ ใส่ข้อมูลและรูปเองทั้งหมด
จำนวน: ใส่จำนวนและหน่วยของแต่ละสินค้าได้ (เช่น 25 กล่อง) แสดงในไฟล์เมื่อเลือกข้อมูล “จำนวน”
รวมเป็นชุด: ติ๊กเลือกหลายรายการในหน้าเดียวกัน แล้วกด “รวมเป็นชุดเดียว” จะได้เลขเดียว มี 2 แบบ (เปลี่ยนได้ที่ “แก้ไขชุด”)
สินค้าหลัก + อุปกรณ์ประกอบ (รวมรูป) เช่น ประตู + มือจับ, กระเบื้อง + ยาแนว, พื้น + บัว: รูปสินค้าหลักกับรูปอุปกรณ์อยู่ในช่องรูปเดียวกัน (ของสูงอย่างประตู วางอุปกรณ์ข้าง ๆ · กระเบื้อง วางมุมขวาล่าง) และใส่หัวข้อให้อุปกรณ์ได้ เช่น “ยาแนวที่ใช้ : …” · สินค้าจากหน้าอื่นใช้เมนู “ย้ายไป… → เพิ่มเป็นอุปกรณ์ของรายการนี้” ได้
รุ่นเดียวกันหลายขนาด เช่น กระเบื้องหลายไซซ์: แสดงสินค้าทุกตัวด้วยชื่อเต็ม พร้อมรหัส ราคา และจำนวนของแต่ละตัว
แก้ชื่อชุด ชื่อที่แสดง รูปของแต่ละรายการ (กดที่รูป) ลำดับสินค้าหลัก หรือแยกชุดได้ · ใช้เมนู “ย้ายไป… → รวมเข้าชุด” เพื่อเพิ่มเข้าชุดที่มีอยู่
ใช้ซ้ำ (ห้องอื่น): ใส่สินค้าหรือชุดเดิมอีกรายการ เช่น กระเบื้องเดียวกันในห้องอื่น มีจุดใช้งานและจำนวนของตัวเอง (ปุ่มที่รายการ, ที่การ์ดผลค้นหา หรือ “+ เพิ่มสินค้าที่มีอยู่ในหน้านี้ → ใช้ซ้ำ”)
ต่อเลขรายการ: ติ๊ก “ต่อเลขรายการจากหน้าก่อน” เช่น หน้า “ห้องน้ำ” มีรายการ 1–3 หน้า “ห้องน้ำ 2” จะเริ่มที่ 4
โปรเจกต์ลูกค้า (แยกงานลูกค้าแต่ละคน)
แถบ โปรเจกต์ลูกค้า ด้านบน: เลือกโปรเจกต์ที่จะทำงาน หรือกด + โปรเจกต์ใหม่ สำหรับลูกค้ารายใหม่
สินค้า หน้า รูป ตัวชี้ จำนวน และข้อมูลโครงการ แยกกันในแต่ละโปรเจกต์ บันทึกอัตโนมัติ ทุกครั้งที่แก้ไข
ชื่อบริษัท โลโก้ และผู้จัดทำ/เบอร์โทร ใช้ร่วมกันทุกโปรเจกต์
ที่เก็บ:
ระบบออนไลน์ (Cloudflare) → เก็บออนไลน์ ทุกคนในทีมเห็นร่วมกัน (โปรเจกต์ที่ลบกู้คืนได้ 30 วัน ที่เมนู “จัดการ → โปรเจกต์ที่ลบ”)
เปิดผ่าน start.bat → เก็บเป็นไฟล์ในโฟลเดอร์ projects ข้าง start.bat (สำรองได้โดยคัดลอกโฟลเดอร์นี้ · โปรเจกต์ที่ลบจะอยู่ใน projects\deleted กู้คืนได้)
เปิดไฟล์โดยตรง → เก็บในเบราว์เซอร์ของเครื่องนั้น
เมนู จัดการ: ทำสำเนา, ส่งออกไฟล์ (.ksproject.json สำหรับสำรองหรือส่งให้เพื่อนร่วมงาน), นำเข้าไฟล์, ลบ
⚠️ ห้ามอัปโหลดโฟลเดอร์ projects หรือไฟล์ .ksproject.json ขึ้น GitHub เพราะมีชื่อ ที่อยู่ และงานของลูกค้า
ระบบออนไลน์ (ไม่ต้องโหลดลงเครื่อง)
ทีมเปิดลิงก์เว็บจากเครื่องไหนก็ได้ ใส่รหัสผ่านของทีม โปรเจกต์เก็บออนไลน์และเห็นร่วมกัน ผู้ดูแลติดตั้งครั้งเดียวบน Cloudflare (ฟรี) ตาม คู่มือติดตั้งระบบออนไลน์

worker.js คือไฟล์ที่วางใน Cloudflare (มี index.html และคู่มือใช้งานอยู่ข้างใน) ไม่มีรหัสผ่านหรือข้อมูลลูกค้า
เมื่อแก้ index.html ให้ดับเบิลคลิก build-worker.bat เพื่อสร้าง worker.js ใหม่ แล้ววางใน Cloudflare อีกครั้ง
รหัสผ่านตั้งใน Cloudflare (Secret ชื่อ APP_PASSWORD) ห้ามใส่รหัสผ่านในไฟล์ใดบน GitHub
วิธีเปิดใช้งานในเครื่อง (start.bat)
มือใหม่: เปิดไฟล์ คู่มือการใช้งาน.html มีวิธีดาวน์โหลด แตกไฟล์ และเปิด start.bat ทีละขั้นตอนพร้อมภาพประกอบ และวิธีแก้ปัญหาที่พบบ่อย

ดับเบิลคลิก start.bat แล้วหน้าเว็บจะเปิดขึ้นเองที่ http://localhost:8800/ เปิดหน้าต่างสีดำค้างไว้ระหว่างใช้งาน ปิดหน้าต่างเมื่อเลิกใช้

start.bat จะรัน server.ps1 ซึ่งเป็นโปรแกรมช่วยในเครื่อง เพราะ HomePro, ตราเพชร และ Eco door ไม่อนุญาตให้เว็บอื่นดึงข้อมูล/รูปโดยตรง โปรแกรมนี้เปิดให้เฉพาะเครื่องตัวเองเท่านั้น และดึงได้เฉพาะเว็บร้านค้าที่กำหนดไว้
