คู่มือสำหรับมือใหม่ · Windows 10 / 11

วิธีเปิดใช้งานผ่าน start.bat เพื่อค้นหาสินค้า HomePro, ตราเพชร และ Eco door

ทำตามทีละขั้น ใช้เวลาครั้งแรกประมาณ 5 นาที ครั้งต่อไปแค่ดับเบิลคลิกไฟล์เดียว

สารบัญ

  1. ทำไมต้องเปิดผ่าน start.bat
  2. ได้ไฟล์มาไว้ในเครื่อง (ทำครั้งแรกครั้งเดียว)
  3. เปิดใช้งาน (ทำทุกครั้งที่จะใช้)
  4. ค้นหาสินค้า HomePro / ตราเพชร / Eco door
  5. เลิกใช้งาน และครั้งต่อไป
  6. แก้ปัญหาที่พบบ่อย

1. ทำไมต้องเปิดผ่าน start.bat

เว็บ HomePro, ตราเพชร และ Eco door ไม่อนุญาตให้หน้าเว็บอื่นดึงข้อมูลไปใช้ตรง ๆ ไฟล์ start.bat จะเปิด “โปรแกรมช่วย” เล็ก ๆ ในเครื่องของคุณ (หน้าต่างสีดำ) ให้ดึงข้อมูลแทน แล้วเปิดหน้าเว็บให้อัตโนมัติ

  • ไม่ต้องติดตั้งโปรแกรมเพิ่ม ใช้ของที่มีใน Windows อยู่แล้ว
  • ใช้ได้เฉพาะเครื่องตัวเอง คนอื่นเข้าไม่ได้ และดึงได้เฉพาะเว็บร้านค้า 4 เว็บนี้เท่านั้น
  • ถ้าไม่เปิดผ่าน start.bat บุญถาวรยังใช้ได้ปกติ แต่ HomePro จะใช้ไม่ได้ และรูปจากตราเพชร / Eco door จะใส่ในไฟล์งานนำเสนอไม่ได้

2. ได้ไฟล์มาไว้ในเครื่อง (ทำครั้งแรกครั้งเดียว)

ถ้าในเครื่องมี โฟลเดอร์ที่มีไฟล์ start.bat อยู่แล้ว (เช่น อยู่บนเดสก์ท็อป) ข้ามไป ขั้นตอนที่ 3 ได้เลย

3. เปิดใช้งาน (ทำทุกครั้งที่จะใช้)

4

ภาพจำลอง: Windows บางเครื่องซ่อนนามสกุลไฟล์ จึงเห็นแค่คำว่า “start”

5

ถ้ามีหน้าต่างเตือนสีน้ำเงิน ให้กดอนุญาต (มักเกิดแค่ครั้งแรก)

Windows จะเตือนทุกไฟล์ที่ดาวน์โหลดมาจากอินเทอร์เน็ตและไม่มีลายเซ็นบริษัท ไฟล์นี้ไม่ได้ติดตั้งอะไรลงเครื่อง

  1. กดข้อความ ข้อมูลเพิ่มเติม (More info)
  2. จะมีปุ่มเพิ่มขึ้นมา กด เรียกใช้ต่อไป (Run anyway)

Windows ป้องกันพีซีของคุณ

ภาพจำลอง: ปุ่ม “เรียกใช้ต่อไป” จะโผล่หลังจากกด “ข้อมูลเพิ่มเติม”

ถ้าขึ้นหน้าต่าง “คำเตือนความปลอดภัย / Open File – Security Warning” แทน ให้กด เรียกใช้ (Run)

6

หน้าต่างสีดำขึ้นมา และหน้าเว็บเปิดเอง

หน้าต่างสีดำคือโปรแกรมช่วย ห้ามปิดระหว่างใช้งาน (ย่อเก็บได้) ส่วนหน้าเว็บจะเปิดขึ้นในเบราว์เซอร์อัตโนมัติ

Material Selection helper
Material Selection helper is running at http://localhost:8800/ - The page opens in your browser by itself. If it does not, type http://localhost:8800/ into the browser's address bar. - Keep this window open while using the page (you can minimise it). - Close this window when you are done.

ภาพจำลอง: ข้อความในหน้าต่างสีดำ

ถ้าเบราว์เซอร์ไม่เปิดเอง ให้เปิด Chrome หรือ Edge แล้วพิมพ์ localhost:8800 ในช่องที่อยู่ด้านบน แล้วกด Enter

7

เช็กว่าเชื่อมต่อแล้ว: ต้องเห็นจุดสีเขียว

ใต้ช่องค้นหาในหน้าเว็บ ต้องขึ้นจุดสีเขียวพร้อมข้อความนี้

เชื่อมต่อโปรแกรมช่วย (start.bat) แล้ว ดึงข้อมูลและรูปได้ครบทุกเว็บ

ถ้าเป็นจุดสีเหลือง “เปิดไฟล์โดยตรง” แปลว่าเปิด index.html เองโดยไม่ผ่าน start.bat ให้ปิดแท็บนั้น แล้วใช้หน้าที่ start.bat เปิดให้ (ที่อยู่ขึ้นต้นด้วย localhost:8800)

4. ค้นหาสินค้า HomePro / ตราเพชร / Eco door

8

เลือกแหล่งข้อมูลก่อนค้นหา

บุญถาวร● HomeProตราเพชรEco door
  • HomePro: ใส่รหัสสินค้า เช่น 1310224 (ดูได้จากหน้าสินค้าบนเว็บ HomePro หรือวางลิงก์หน้าสินค้าทั้งลิงก์ก็ได้) แล้วกด ค้นหา สินค้าจะเข้างานนำเสนอให้ทันที
  • ตราเพชร / Eco door: เว็บไม่มีรหัสสินค้า ให้ใส่ชื่อสินค้า เช่น ครอบสันโค้ง, ประตูห้องน้ำ แล้วกด ค้นหา จากนั้นกด + เพิ่มลงงานนำเสนอ เฉพาะตัวที่ต้องการ
  • บุญถาวร: ใส่รหัสสินค้าเหมือนเดิม
เคล็ดลับค้นหาหลายรอบได้ สินค้าจากทุกเว็บจะสะสมรวมอยู่ในงานนำเสนอเดียวกัน ถ้าค้นด้วยชื่อแล้วไม่เจอ ลองใช้คำสั้นลง เช่น “ประตู” แทน “ประตูห้องน้ำสีขาว”

5. เลิกใช้งาน และครั้งต่อไป

9

เลิกใช้: ปิดหน้าต่างสีดำ

กดปุ่ม ✕ ที่มุมขวาบนของหน้าต่างสีดำ (ควรสร้างไฟล์งานนำเสนอให้เสร็จก่อน เพราะสินค้าที่จัดไว้จะหายเมื่อปิดหน้าเว็บ)

ครั้งต่อไป: ดับเบิลคลิก start.bat อีกครั้งเท่านั้น

ไม่ต้องดาวน์โหลดหรือแตกไฟล์ใหม่ ถ้าเผลอดับเบิลคลิกซ้ำตอนที่เปิดอยู่แล้ว โปรแกรมจะเปิดหน้าเว็บเดิมให้เอง

ทำทางลัดบนเดสก์ท็อป (ไม่บังคับ)คลิกขวาที่ start.bat → ส่งไปยัง (Send to) → เดสก์ท็อป (สร้างทางลัด) · บน Windows 11 ให้กด แสดงตัวเลือกเพิ่มเติม (Show more options) ก่อน

6. แก้ปัญหาที่พบบ่อย

อาการวิธีแก้
หน้าต่างสีดำขึ้นว่า “server.ps1 was not found”เปิด start.bat จากในไฟล์ ZIP ให้ทำ ขั้นตอนที่ 3 แตกไฟล์ แล้วเปิด start.bat จากโฟลเดอร์ที่แตกแล้ว
หน้าต่างสีดำขึ้นแล้วปิดไปทันทีลองแตกไฟล์ไว้ที่เดสก์ท็อปใหม่ (ชื่อโฟลเดอร์ไม่ควรยาวมาก) แล้วดับเบิลคลิก start.bat อีกครั้ง ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ ถ้ายังไม่ได้ อาจเป็นเครื่องบริษัทที่ปิดการใช้ PowerShell ให้ติดต่อฝ่าย IT
ขึ้นว่า “Could not open a local port”มีหน้าต่างสีดำอีกอันเปิดอยู่ ให้ปิดหน้าต่างสีดำทั้งหมด แล้วดับเบิลคลิก start.bat ใหม่
โปรแกรมป้องกันไวรัสแจ้งเตือนหรือย้ายไฟล์ไปstart.bat และ server.ps1 เป็นไฟล์ข้อความธรรมดา เปิดอ่านด้วย Notepad ได้ ถ้ามั่นใจว่าได้ไฟล์จากแหล่งของบริษัท ให้กดอนุญาต (Allow / Restore) ในโปรแกรมป้องกันไวรัส
หน้าเว็บขึ้นจุดสีเหลือง “เปิดไฟล์โดยตรง”ใช้หน้าที่ที่อยู่ขึ้นต้นด้วย localhost:8800 เท่านั้น ถ้าปิดหน้าต่างสีดำไปแล้ว ให้ดับเบิลคลิก start.bat ใหม่
ค้นหาแล้วขึ้นว่า “เชื่อมต่อ … ไม่ได้”ตรวจว่าอินเทอร์เน็ตใช้ได้ และหน้าต่างสีดำยังเปิดอยู่ แล้วลองใหม่ ถ้าเว็บต้นทางปิดปรับปรุงหรือเปลี่ยนระบบ อาจค้นหาไม่ได้ชั่วคราว
HomePro ค้นหาไม่เจอตรวจรหัสสินค้าอีกครั้ง (ตัวเลขในลิงก์ homepro.co.th/p/1310224) หรือวางลิงก์หน้าสินค้าทั้งลิงก์
ใช้ Mac ได้ไหมstart.bat ใช้ได้เฉพาะ Windows บน Mac ยังเปิด index.html ค้นหาบุญถาวรและ Eco door ได้ตามปกติ
ภาพในคู่มือนี้เป็นภาพจำลองเพื่ออธิบาย หน้าตาจริงอาจต่างเล็กน้อยตามรุ่น Windows และภาษาที่ตั้งไว้
